# V5 正式实验执行流程

当前唯一基线是根目录的 `05_FC_Equivalence_Class_KD_GoNoGo_Pilot_PRD_v5_FINAL.md`。

```text
P0  固定模型 revision、tokenizer、template、seed、环境
 ↓
P1  选择单一主数据源 + 固定 V5 splits + 实现 deterministic canonicalizer
 ↓
P2  14 类 canonicalizer tests + audit
     └─ 失败：Pipeline Fail → 修复并重跑
 ↓
P3  300 条 opportunity_probe，每条 Teacher 自然采样 8 次
 ↓
P4  surface dedup → validate → canonicalize → Teacher 重新 sequence-score
 ↓
P5  Data Opportunity Gate
     ├─ Strong/Weak Pass → 继续
     └─ Provisional No-Go → 100 条×16 次唯一确认 → 仍失败则 Research No-Go
 ↓
P6  0.6B Tiny Overfit + Canonical/Token/Candidate/KL/Permutation/Gradient Tests
 ↓
P7  用 V5 Train Gold 训练公共 Qwen3-1.7B S0
 ↓
P8  在自然等价 support 上计算 Student–Teacher Intra-class Gap
     ├─ Pass → 继续
     └─ Fail → Research No-Go / Weak Go
 ↓
P9  构造并冻结 V5 Train Candidate Pool（每条 3–6 个）
 ↓
P10 Candidate/Class Teacher cache
 ↓
P11 锁定 STAR top-k FKL 的精确训练序列
 ↓
P12 Token FKL cache
 ↓
P13 从同一个 S0 运行四分支
     ├─ SFT Continuation
     ├─ Token KD / top-k FKL
     ├─ Candidate KD
     └─ Equivalence-Class KD
 ↓
P14 Internal + held-out natural equivalence + BFCL
 ↓
P15 Strong Go / Weak Go / Research No-Go
```

## 三个职责必须分离

```text
validate_call(raw_call, schema)
    → 只判断 parse/schema 合法性

canonicalize_call(parsed_call, schema, runtime_rules)
    → 只定义完整调用身份，不看 Query

evaluate_call(query, canonical_call, gold_call)
    → 判断调用对当前 Query 是否正确
```

V4 的 `correct/wrong_function/wrong_arguments/invalid` 仍可用于错误分析，但不得定义 KD class。V5 class key 只能来自稳定的 `canonical_signature`；不同 invalid candidates 保持 singleton identity。

## Gate 前后资源边界

- Opportunity Gate 前不训练正式 S0，不冻结 Train Candidate Pool，不做大规模 Teacher cache。
- Opportunity Probe 不进入正式 KD Train Candidate Pool。
- Gap Gate 前不构造正式 Train Candidate Pool。
- Internal Test、自然等价 held-out cases 和 BFCL 不进入训练或 checkpoint 选择。
- BFCL 不参与 lambda、candidate temperature、early stopping 或候选构造。
- Teacher sampling 只发现 support；Teacher 概率来自重新 sequence-score，不来自样本频率。

## V4 资产边界

- 已有 ToolACE/xLAM 审计可支持主数据源选择，但 V5 首轮必须只选一个主训练来源。
- 旧 3,250 条混合 split、S0、严格 K=6 候选池和人工审核表保留为历史资产。
- 只有在数据、模板、canonicalizer 和 Gate 定义与 V5 完全一致时，旧模型或缓存才允许正式复用；否则只能用于工程回归。
