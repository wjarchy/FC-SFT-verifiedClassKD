# V7 训练信号分析

## 先说结果怎么看

这里比较两种训练方法推动模型参数变化的力量。数值越大，说明这一步推动得越强；方向接近，说明两种信号在推动相近的变化，方向相反则会互相抵消。

完整候选蒸馏（`Candidate KD`）同时学习不同功能类别和同类写法偏好。功能类别蒸馏（`Class KD`）只学习不同功能类别。

## 固定计算范围

- 触发原因：Balanced-336 训练 1 轮时，`Class KD` 明显较差；训练 4 轮后差距缩小，因此检查它是否只是训练信号较弱。
- 模型固定为正式的初始学生模型。样本固定为 Balanced-336 在随机种子 42、首轮训练的第一组，共 16 条。
- 每条样本都在全新进程中单独加载模型，结束后释放显存；最后只在普通内存中汇总。这样只解决显存累积，不改变样本、模型或计算公式。
- 每条样本内再把 4 个候选逐个计算。先精确求出损失对 4 个候选分数的影响，再按链式法则逐个求参数信号并相加；单元测试确认它与一次性直接求导一致。
- 模型关闭随机丢弃，因此同一输入可重复计算。这里分析的是训练目标本身，不代表一次真实训练更新。
- 公式为 `L_candidate = L_inter + L_intra`，`L_class = L_inter`。其中 `inter` 是不同功能类别之间的信号，`intra` 是同一功能类别内部不同写法之间的信号。

## 16 条样本的平均训练信号

| 衡量内容 | 数值 |
|---|---:|
| 完整候选蒸馏的信号长度 | 0.81783132 |
| 功能类别蒸馏的信号长度 | 0.79579350 |
| 不同功能类别之间的信号长度 | 0.79579350 |
| 同类不同写法的信号长度 | 0.07606214 |
| 完整候选 / 功能类别信号长度 | 1.0277 |
| 同类写法 / 不同功能类别信号长度 | 0.0956 |
| 两部分方向相似度（1 同向，-1 反向） | 0.249500 |
| 分解误差（越接近 0 越好） | 1.920e-03 |

完整候选信号只比功能类别信号长 2.77%。同类写法信号约为类别间信号的 9.56%，方向上轻微同向。因而“小数据训练 1 轮时的巨大差距”不能只用 `Class KD` 信号太弱来解释。

分解误差占完整候选信号的 0.23%；逐样本最大相对误差为 0.96%。损失值的分解误差为 0。该数值量级不会改变上面的强弱和方向判断，但说明 4 位量化模型的三次独立求导并非逐位完全相等。

## 结论边界

- `Class KD` 的信号按定义就是不同功能类别之间的信号；`Candidate KD` 还多了同类不同写法的信号。
- 信号长度和方向只能帮助解释现象，不能代替正式生成评测，也不能单独证明扩大数据后的变化由它造成。
- 本分析只有一组预先固定的 16 条样本，不能把它当成全部训练数据上的统计定论。
- 独立核对已确认：16 条样本顺序、输入文件哈希、模型哈希、损失分解、报告数值和显存上限全部一致；所有数值均为有限值。
