# 冒烟测试与小样本过拟合结果

日期：2026-08-12；硬件：RTX 3090 24GB；配置：`configs/rtx3090.yaml`。

## 冒烟测试

使用 4 条人工构造样本和本地 Qwen3-0.6B 权重，结果如下：

- 标准 SFT 损失为 0.6238。
- LoRA 参数获得非零梯度，冻结的基础模型参数没有梯度。
- 候选调用文本能够按 Qwen3 工具调用格式编码，并计算完整输出序列的对数概率。
- 类别聚合、Class KD 损失和 LoRA 反向传播完整通过；损失为 0.006519。
- LoRA 适配器保存和读取路径正常。
- 显存峰值为 3,034.7 MiB。
- 程序最终输出 `SMOKE_OK=true`。
