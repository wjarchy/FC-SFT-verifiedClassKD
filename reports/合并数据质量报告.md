# ToolACE 与 xLAM 合并数据质量报告

> **V4 历史数据报告。** 本报告验证的是 ToolACE+xLAM 3,250 条混合划分。V5 首轮要求选择
> 一个主训练数据源并单独固定 Opportunity Probe，因此本报告只作为数据源选择证据，不是 V5 manifest。

## 技术结论

正式 3,250 条数据已经通过结构质量检查，可以进入公共 S0 训练。全部数据 ID 和规范化问题文本唯一，五个划分互不重叠，Gold 结构错误为 0，BFCL 高相似剔除集合残留为 0，清单中的文件哈希全部一致。

仍需保留一个限制：xLAM 的必填信息是根据实际类型字符串和默认字段保守推断的，不是上游显式 `required`；xLAM 默认值因噪声较大而全部不参与等价判断。该选择降低假等价风险，但可能少识别一部分真实默认值等价表达。

## 正式数据组成

| 来源 | 数量 | 占比 | 处理方式 |
|---|---:|---:|---|
| ToolACE | 2,103 | 64.71% | 从原始 Team-ACE 恢复参数说明后全部保留 |
| xLAM | 1,147 | 35.29% | 从 17,924 个去重、去泄漏问题中按 seed=42 抽取 |
| 合计 | **3,250** | **100%** | 全部进入且仅进入一个划分 |

选择全部 ToolACE、再由 xLAM 补足，是为了保留已经严格恢复参数说明的高置信数据。若直接从全部可用数据等比例抽样，xLAM 会占约九成。

|---|---:|---:|---:|---|

任意两份划分的 ID 交集都是 0。全部 3,250 个 ID 唯一，按 NFKC、转小写、去标点和合并空白后的问题文本也全部唯一。

## 发现并修复的问题

| 问题 | 证据 | 风险 | 处理 | 当前状态 |
|---|---|---|---|---|
| xLAM 没有显式 `required` | 362,482 个参数全部缺失 | 缺参数调用可能被误判正确 | 根据 `optional` 和默认字段保守推断 | 已修复，有中等残余不确定性 |
| xLAM 默认值类型混乱 | 64,099 个空字符串，且存在整数/布尔类型不匹配 | 制造假默认值等价 | xLAM 默认值全部不参与等价判断 | 已消除该风险 |
| xLAM 复合类型格式多样 | 包含 List、Tuple、set、Dict、Callable | 验证器可能放弃类型检查 | 支持可映射的顶层 JSON 类型；Callable 整条剔除 | 已修复 |
| ToolACE 存在联合类型 | 29 个参数曾被读成字符串形式的列表 | 对这些参数放弃类型检查 | 保存为 `integer|null` 等联合类型并逐成员检查 | 已修复 |
| 规范化重复问题 | 暂存版发现 2 组标点/空白变体；全量 xLAM 有更多同类重复 | 同一问题可能跨划分泄漏 | 按规范化问题文本去重后再划分 | 正式残留 0 |
| xLAM 与 BFCL 高相似 | 3 条完全相同，共 102 个高相似问题、155 个重复原始行 | 虚高 BFCL | 按规范化问题文本整体剔除 | 正式残留 0 |

## 有效性检查

- Gold 在当前工具参数说明下结构合法：3,250/3,250。
- 参数类型都属于支持的 JSON 顶层类型或明确联合类型。
- xLAM 中保留的默认值数量：0。
- ToolACE 中保留的原始明确默认值：3,286。
- 必填参数共 13,326 个，可选参数共 15,252 个。
- 数据清单中的所有 SHA256 与实际文件一致。
- 正式全集 SHA256：`472b5b8538c5ed12edeccf784db9ee331385e3f9c0077cdeb6515d09e6977ddf`。

## Diagnostic 候选初检

250 条 Diagnostic 全部可以构造至少一个结构化错误候选。101 条至少包含两个文本形式不同但验证器判断正确的候选，占 40.4%。

当前规则候选数量分布：K=3/4/5/6/7 分别为 29/29/105/79/8。这只是 S0 前的规则候选检查，不是最终候选池。后续仍需加入 S0 真实错误，并将每条确定性整理为严格 K=6。

## 尚不能由本检查证明的内容

- 结构合法不等于用户语义一定正确；xLAM 上游声称做过人工检查，但本项目尚未重新独立审核其语义正确率。
- 文本相似度检查不能证明不存在所有语义泄漏，只能可靠发现完全相同和高表面相似问题。
- 验证器的独立人工准确率仍需在最终 K=6 候选池上审核。
- 当前等价候选覆盖不代表自由生成的等价鲁棒性结果。
